## 公開に必要な品質ゲート

1. **保護種・特定外来生物の照合**：2026年10月時点の公的リストに基づき、保護・規制情報と出典を別項目として設定する。レア度★と法定の絶滅危惧指定は同義ではない。
2. **毒性と食味**：食味★は主観評価に過ぎず、食用にして安全かどうかは意味しない。フグや毒棘のある魚、希少魚、元データの記載名が不明瞭な魚には味評価を無理に出さない。
3. **古い呼称・シノニム・品種**：255件の一部は旧分類・別表記。完全一致ベースでは統合しない。正式な分類資料と照合してから正規魚種マスターへ紐付ける。
4. **調査・DNA記録**：源流資料の水系・魚名・年度を維持。eDNA陽性は魚を実際に捕獲・目視した記録ではない。
5. **出典・利用権利・実機UX**：公的研究資料・第三者権利の確認、iPhone Safari／PC実機テスト、人の最終編集承認が終わるまで**本番へ出さない**。
