# つりくえ！｜魚図鑑のレア度・味・一言メモ 研究作業 v0.16

2026-10-20。既存 v0.15 魚類先行ZIPから、**639の原資料掲載名**を全件取り出して、魚名の健全性を見直す研究。**本番公開未許可、WordPress未変更。**

## 優先順位

現時点の作業優先順位は「まず魚種の星評価と一言メモを作る」へ変更。ただし**データ収集・分類法令区間整備・魚×河川の紐付け・その他生物収録**は引き続き後段の課題として保持。魚だけを完成させてから河川一覧の全国拡張に戻る。

## 一次資料の調査結果を使う際の注意

`outputs/fish_639_taxon_labels_for_editor_v16.csv` は名前・元資料での出現グループ・採集／DNA方法区分を抽出。639は魚種数ではなく掲載名数。歴史的な調査では魚類欄に甲殻類・両生類・貝・カメが混入していた。

`nonfish_source_labels_v16.txt` に**手動で照合した50の魚以外の掲載名**を完全一致で隔離。ギンガメアジ、ズナガニゴイ、ビワヒガイ、ヒガイ属は紛らわしい名前でも**魚**。文字列内の「ガニ」「ガイ」で機械的に削除するのは禁止。

「属」「科」「類」「複数候補」「型」や「○○/△△」などの記載名は**正式に種まで決まっていない**。元の名前を残し、星・味を作らない。今後の正式な同定・別名の紐付け作業は別途行う。単なるラテン語学名の記載だけでは同定確証とせず保留する。

## 120の独自コンテンツ草案

`fish_editorial_drafts_v16.csv` は、元資料で頻繁に出る魚を中心に**120魚名の個別コメント・レア度1～5・味1～5（評価不能・不適切な場合は空欄）**を作成。すべて **AI_EDITORIAL_DRAFT_NOT_FACT_CHECKED** であり、星も事実としての保証ではない。人間の承認を装うことはしない。記述・危険性・分布・保全の可否を専門資料で確かめてから実サイトに掲載する。

レア度の素案は「全国での一般的な遭遇のしやすさ」であり、個々の河川での出現回数や保全指定ランクの代用ではない。星1は広く出会う、星3は場所／環境を選ぶ、星5は全国でもかなり珍しい**編集上の指標**。具体的な採捕地点と繁殖場所は載せない。

味は「一般の食文化での評価」であり、料理法・個体差・季節で変わる**主観的な楽しさの指標**。**魚を食べて安全かどうかの判断材料にはしない**。味を評価できない、小魚、毒魚、保護が必要な魚、未同定名は**空欄**。独自評価に客観的・医学的・法的な効力はない。

### 現在の魚図鑑の画面仕様

- 既存511の調査資料上の河川名グループを残し、原資料の魚名・DNAの別区分を維持する
- 魚でない名前は表示対象から外すが、**元資料は過去のv0.12／v0.15に保存**
- 種まで特定していない名称は「種名未確定・星評価なし」
- AI作成メモは「仮評価・要確認」を星の前に明示。公開用の★とは区別
- 魚ごとの資料リンク、過去の調査と環境DNA検出区分を維持
- プレビューZIPは研究用であり、実サイトへ公開・自動同期しない

## 今後の必要な監査

1. 和名・学名の最新照合と疑似的な重複統合の排除。特に種類まで分からない記録は別名魚種へ勝手に足さない。
2. 各メモの記載事実・食味・毒性・規制・絶滅危惧種指定の裏取り。保全対象は味より保護情報を優先。
3. **120以外**の記載名の追加原稿（同じ形式の繰り返しではなく、その魚らしい具体性）。
4. 複数資料を使った場合の権利・出典・第三者権利の確認。研究ブランチにあるからといって商用許諾済みにはならない。
5. 人間の最終承認・スマホSafari／PCの操作試験後、はじめて本番公開を提案。
