# レクサスUX参考価格チェック v0.15 ― カラー撤去・一般市場の参考表示を改善

記事内で3条件（グレード・年式・走行距離）を選び、支払総額ベースの価格帯を**一般中古車／レクサスCPOの2段**に分けて見る軽量静的ツール。MySQL・外部APIは不要。**ツール内にアフィリエイトリンクやPRボタンは置かない。広告導線は記事本文側に別設置する。**

## 本番公開条件
- データJSONの `publication_reviewed` は **true**、`limited_sample_release=true`。掲載例に限定した参考価格として公開候補とする。市場全体の相場と誤認させないよう、少数サンプル・調査日・年式等の不一致を表示する。
- ローカルPCの確認用 `?preview=1` では実サイトの公開制御を迂回しない。公開後はJSONの承認フラグと60日以内の調査日が揃う場合だけ価格を表示。
- 調査用集計は22種類。同じ車両を異なる条件で再集計したものがあり独立22標本ではない。ほとんどの4条件組合せはカバーされていないため、未計算時は「集計中」を表示。
- このブランチではまだ **Xserver専用プレビュー**まで。プレビューのHTTPS一致とWPパーツ確認後、別の安全な本番公開PRを作る。

## WordPress記事用の埋め込み（公開許可後）
```html
<iframe title="レクサスUXの中古車参考価格（一般中古車・CPO比較）"
  src="https://tsurikue.com/ux-price-checker/?model=250h&amp;grade=c&amp;year=2021"
  loading="lazy" referrerpolicy="strict-origin-when-cross-origin"
  style="display:block;width:100%;height:620px;border:0;border-radius:12px"
  aria-label="レクサスUXの中古車参考価格"></iframe>
```
- 記事ごとに URL の `model=250h`、`grade=fs`、`year=2021` などを変更。値はツール内の選択肢で検証される。
- 複数記事で同じ1つの静的URLを共有するため、価格更新はXserver上のJSONを置き換えるだけ。
- WordPress本文の短縮コードやプラグインを増やさず、記事ごとにHTMLブロック1個でよい。
- ツールの iframe URL は検索エンジン向けに noindex。価格データはSEOを目的とした車両一覧の転載ではない。

## 出典・免責
- 数字は掲載支払総額の少数事例による試算。値上がり・値下がり、車両ごとの状態、支払条件等の差を補正していない。
- ツール本体には広告・ガリバーへのリンク・トラッキングピクセルを入れない。広告を掲載する記事では記事本文側でPR表記・リンク先・成果条件を個別管理する。

## 更新・保守
- `python tests/test_release.py` でJSONとHTMLの安全条件を検証。
- JSを別途 `node --check` でチェック。
- 価格データ更新時に出典・掲載日時・CPO区分・重複・集計件数・偏りを監査。年式・グレードの網羅率を確認してから publication_reviewed を変更する。
- 研究用の個票や個人情報は公開リポジトリ・Xserverに置かない。

## v0.12 構成・集計（2026-11-09）
- 一般中古車29件（独立した旧UX300e 7件の集計は個票未再突合）＋レクサスCPO36件の監査メモから、22個の条件別集計候補を生成。22個は同じ車両を条件違いで再集計したもので独立サンプル数ではない。
- グレード・年式に完全一致する集計がない場合、**同年式・全グレード**、または**当該年を含む最大2年の全グレード**に限って目安を表示し、「グレード混在」「年式範囲」などを明示。条件に合うデータが足りない場合は「集計中」。
- 走行距離1万km刻みは残すが、標本が不足するため未反映の場合は明記。カラー選択は撤去済み。条件が絞り込めないなら架空の補正を行わない。
- `publication_reviewed=true` / `research_preview_only=false` / `limited_sample_release=true` として少数掲載例の参考帯に限定。未確認の市場代表性は主張しない。
- `tests/test_release.py` および Playwright のオフライン描画テストを実施。広告撤去前は高さ約710〜820px、撤去後はスマホ幅320〜600pxで約544〜582px。WordPressのiframeは**620px**を推奨（広告をツールから除外した後）。以前の545pxは旧広告付き版のテスト記録。v0.13では広告を外し、iframe高さを620pxに縮小。
- UX200・UX250hは2023年式まで、UX300hは2024年式から（※年式は初度登録年を指すため、後年登録の在庫が例外的にある可能性あり）。
- CPOに旧・新年式が混じると比較が不正確になるため、選択年から大きく離れた集計を自動転用しない。
- GitHub CI／XserverプレビューのHTTPS一致／実際の記事埋め込みは公開前の必須確認事項。広告のリンク・PR表記は別途、記事側で確認。

## v0.13 — 相場ツール単体化（2026-11-09）
- ユーザー方針で**ガリバーA8のPR・ボタン・画像ピクセルをツール内から完全撤去**。アフィリエイトボタンはWordPress記事本文の別位置に設置する。
- 4条件検索・一般中古車とCPOの2段相場表示は維持。価格JSONの研究用・公開停止ゲートは維持。
- 広告撤去後のローカル描画でツールの高さは320〜600px幅に対して約544〜582px。共通iframeの高さを620pxに縮小。
- Xserverでの隔離プレビュー配信・GitHub自動検証を更新。WordPressの掲載・公開有効化は依然として別判定。

## v0.14 限定サンプルの公開条件（2026-11-10）
- 2026年11月9日の掲載例を基に、一般中古車とCPOを必ず別集計する。
- 独立標本は一般中古車の監査候補29件（旧UX300eの別調査例7件）・CPO36件。22件の集計結果は独立台数ではない。
- 金額は**市場全体の代表値ではなく観測例の参考帯**。中古車保証・地域・装備・走行距離・カラーによる違いは不完全。
- 広告・A8リンク・PRピクセルはツール内に置かず、広告が必要なら記事側で管理する。
- 価格は60日を超えると表示を停止する。定期更新なしの放置を避ける。
- 本番公開フォルダとSWELLブログパーツの公開切替は別PRで安全に実施する。

## v0.15 更新（2026-11-10）
- カラーは実測価格への補正に使えないため入力から撤去。グレード・初度登録年・走行距離の3項目。
- 一般中古車12種類とCPO10種類の少数集計候補を維持（独立した22台ではない）。
- 厳密な年式・グレードに一致する集計がない場合、同モデルで選択年を含む最大5年の集計を**複数年式・グレード混在の参考値**として表示する。異なるモデル、選択年を含まない集計は流用しない。
- 同年式・同グレードの集計を優先し、幅広い集計を使った場合は対象の年式範囲とグレード混在を明示。
- 走行距離帯ごとの確かな補正はまだできない。選択時は「走行距離未反映」と明示。
- `node tests/test_search.js` で一般中古車・CPO・誤った年式流用を自動検査。
- SWELLブログパーツ4505はそのまま。XserverでHTML/JSONを共通更新するため記事側の変更は不要。
