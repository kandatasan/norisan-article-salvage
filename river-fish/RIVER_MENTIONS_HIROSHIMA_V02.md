# 広島県 河川名候補台帳 v0.2（小河川拡張）

作成：2026-10-18。**Web公開前の調査用データ**。既存の河川マスター v0.1（66河川／15水系）と別管理。

## 今回増えたもの

- **公式資料掲載98行／異なる河川名称90種類**の「河川名掲載情報」を追加
  - 尾道市：24掲載行
  - 三原市：33掲載行
  - 世羅町：34掲載行
  - 広島市：7掲載行（準用河川5＋普通河川の例示2）
- **98件を新規の独立河川として数えない**。同名が市町村をまたぐ場合も、出典の掲載行をそれぞれ残す。既存66河川との名称重複もある。
- 三原支所のページにある「単独河川」は**そのまま「単独河川」と記録**。市の普通河川に勝手に読み替えない。
- **河川名を見つけたことと、その河川に魚がいることは別**。追加候補の水系、直接合流先、魚類観測、同名河川との統合は未判定。

## データファイル

- `river_name_mentions_hiroshima_v02.csv`：新しい調査行98件（市町村・出典URL・行政上の記載区分・ページ年月日・レビュー状態）。
- `river_mentions_v02.py`：旧66河川＋98の掲載行を別テーブルに格納するSQLite生成と、名前・地域・記載区分の検索。
- `test_river_mentions_v02.py`：諸木川、同名大谷川、尾道・三原・世羅・広島市の記録の分離など11件のQA。
- 既存の `river_registry_v01.py`、魚類集約2,285件には変更なし。

## 検索例

```bash
python river-fish/river_mentions_v02.py --build
python river-fish/river_mentions_v02.py --name 駒月川
python river-fish/river_mentions_v02.py --name 大谷川
python river-fish/river_mentions_v02.py --municipality 広島市 --class-name 準用河川
python -m unittest discover -s river-fish -p 'test_river_mentions_v02.py' -v
```

検索結果は `canonical_rivers`（v0.1の既存河川）と `unresolved_mentions`（v0.2の登録候補）を分離表示。後者の `watershed`、`direct_parent`、`fish_occurrences_for_this_river` は **null**。名称一致は、河川同一性の証明にはならない。

## 権利と品質

- 今回記録したのは出典に出てくる**河川の名前等の事実**だけ。元ページの文章・表・地図・写真は転載していない。
- 国土数値情報の旧W05（非商用指定）を取り込んでいない。
- GitHubのデータは公開リポジトリにあるが、**つりくえ！のサイトに転載・公開したわけではない**。商用利用・公表前の出典表示と利用条件の確認は引き続き必要。
- 標準名と地方名・同名異河川・管理区分・直接親河川を別管理し、意図しない統合を避ける。

## 次の工程

実際の流域・位置が確認できる許諾済み行政資料で水系と河川の同一性を確定する。その後、より小さな川・準用／普通河川を自治体別に増やし、個別の魚類調査が見つかるものに限って魚種を紐付ける。
