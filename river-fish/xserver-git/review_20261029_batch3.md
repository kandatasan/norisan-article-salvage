# 河川魚類接続レビュー 第3便（2026-10-29）

対象は既存の未接続河川名グループのみ。河川名グループの追加・削除・統合は行わない。

## 採録

- 公的資料2点を再確認し、5既存グループ、魚名13件をB「資料に掲載された生息魚」として接続候補化した。
- 埼玉県の越辺川は、県環境科学国際センターの魚類研究成果から作成された県資料で「越辺川産オイカワ」とされた1件を採録した。
- 滋賀県の野洲川、山賀川、葉山川、草津川は、令和6年3月認可の現行河川整備計画で各河川の生息・確認魚として明記された一般魚を採録した。
- 山賀川は原資料表記「山賀川(新守山川)」を `documented_river_label` に保持し、既存の河川名グループ名は変更していない。
- 詳細地点・区間は収録していない。原資料の魚名を確定種へ置換していない。

## 保全・同一性審査

- 滋賀県資料中でレッドリスト区分が併記された魚、貴重種・要注目種等とされた魚は公開接続から除外した。
- 滋賀県レッドデータブック2025年版選定種リストを追加確認し、今回採録する魚名が同リストに掲載されていないことを確認した。
- 野洲川へ流入する用排水路の魚名は、本川へ割り振っていない。
- 狼川と家棟川は資料に魚名があるが、いずれも保全上の配慮が必要な魚のため保留した。
- 資料に河川名と魚名の対応がない十禅寺川は接続していない。

## 集計境界

- 第2便反映後の接続数は425／1,127グループ（37.71%）。
- この5グループがmainと隔離テスト環境に反映された場合は430／1,127（38.15%）。50%の564グループまで残り134グループ。
- 本番公開、WordPress、biota APIには反映しない。
