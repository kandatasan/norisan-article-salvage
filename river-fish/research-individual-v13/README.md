# 日本の河川大図鑑｜東広島市2024年度底生生物実地調査 v0.13

2026年10月20日 / **研究のみ。本番WordPress・公開API・MySQLを変更していない。**

## 元資料を実際に取得・検証した結果

- 東広島市の[令和6年度 主要水域（河川）における水生生物調査等業務報告書](https://www.city.higashihiroshima.lg.jp/material/files/group/204/R6suiseiseibutsu.pdf)（PDF **5,982,918バイト**）をGitHub Actionsから直接取得した。
- 固定SHA256：`39dd3545bb9f8b635569f836a21ea0cc36d78e339e85489e9b9fa9ee80d25b67`
- 調査日：**2024年11月18〜19日**。調査機関は原本記載、対象水系は**黒瀬川、沼田川、太田川、瀬野川、三津大川**。
- **23調査地点**の底生生物の実地採集調査（1mmの網で採取し記録後に放流）。**環境DNAではない**。
- PDF本文表3-2-1に列挙されているのは各地点の**代表的な指標生物**であり、野帳にある全確認生物名ではない。無理に全種リストと呼ばず、資料表記通り**21の河川名×代表指標分類群組**を抽出。
- 重複する調査地点を河川名単位でまとめると**19河川名・水系の候補**。既存511研究用図鑑の中国地方分には、この**19組の水系×川名の完全一致が見つからなかった**。ただし511にそのまま加算したものではない。名前・管理区間の同一性を追加精査するまでは別レイヤーに保管。
- 採集地点番号、地図、緯度経度、個別位置、調査員名は成果物CSVから除外。

## 実際の成果

- `extract_higashihiroshima_benthos_v13.py`：公的PDF取得→SHA→原本の23行ごとの水系・地点の対応・代表分類群を照合、元の511研究用図鑑と比較。
- `outputs/higashihiroshima_2024_benthic_indicator_aggregated_v13.csv`：水系×河川名×代表指標分類群、記載年度、出典、採集手法、原文分類群名。**21行**。
- `outputs/higashihiroshima_2024_benthic_qa_v13.json`：原本SHA、抽出23地点、5水系、19河川名候補、実地調査との分離、権利ブロック。
- `.github/workflows/river-higashihiroshima-benthos-v13.yml`：原本を一時ダウンロードしてPDFの表と検証、研究ブランチに確認済み成果のみ保存。PDF原本バイト自体は本リポジトリに再配布しない。
