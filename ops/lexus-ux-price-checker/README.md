# UX中古車相場ツール v0.9 — CPOを調査対象に復帰

## 方針
UXの相場目安には一般中古車だけでなくCPO（レクサス認定中古車）も含める。ただし保証・整備条件が異なるため、**中央値を単純合算しない**。

## 表示
- 入力は従来の4つ（グレード・年式・走行距離・カラー）。
- 一般中古車・CPOの両方に同条件データがあれば、区分別の価格帯と中央値を内訳表示。上段は両区分の参考帯を包む幅であって、混合市場の中央値ではない。
- どちらか片方しかデータがない場合は、その区分のみ表示。他方は「集計中」。
- 走行距離やカラーのデータ不足は画面上に明示する。年式やグレードの違う価格を自動転用しない。
- CPOの2024年式UX300h version Lの5件から、研究用の参考帯470〜500万円、中央値485.4万円を追加。

## 公開制御
調査サンプルの代表性・他社掲載重複・価格の更新・利用条件が未確認。引き続き `publication_reviewed=false`, `research_preview_only=true` とし、価格はlocalhostの`?preview=1`のみ。PRは下書きのまま、WordPress本番は未変更。

## ガリバー
「まだネットに出る前の、お得なUXが見つかるかも？」の可能性訴求は維持。非公開在庫の有無や割安さは保証しない。

## v0.10 — 一般中古車／CPOを常時2段表示（2026-11-09）
- 読者の入力は従来どおり4項目（グレード・年式・走行1万km単位・色）。
- 参考価格を「一般中古車」「レクサスCPO」の**固定2行**に分離。上部で両区分を合算した外側の価格幅は表示しない。
- 区分ごとに参考価格帯・中央値・件数。データが足りない方は「集計中」。
- 走行距離別のサンプルが不足する場合と、カラー差を反映できない場合はその区分ごとに注記。
- ガリバーへのPR導線（ネット公開前の車両に出会える可能性）はそのまま。
- 現時点で価格は研究用サンプルのみ。本番表示は安全制御で停止したまま、PRは下書き維持。
