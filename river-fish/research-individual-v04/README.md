# 九州の個別河川生物データベース調査 v0.4｜106 → 115河川

調査・実装日：2026-10-20 JST  
研究ブランチ：`research/river-individual-kyushu-20261020`  
対象：日本の河川大図鑑・研究用、**公開／本番反映なし**。

## 今回の結論

九州地方整備局20水系に属する「河川の情報図」配布資料の河川名を、従来の未確定B判定生物記録と照合。さらに、気象庁2026年4月22日資料の**個別河川名と10桁河川番号が同じ行に掲載**される記録を、全国河川コードと3系統で突合した。

| 判定 | 数値 | 確実性 |
|---|---:|---|
| 従来から全国の個別河川コード確定 | 106河川・155,156河川文脈記録 | 旧研究 v0.3 をSHAで復元確認 |
| **九州で新たに個別河川コードが確定** | **9河川・21,621河川文脈記録** | 独立した気象庁コード＋国交省水系・河川名＋全国コード表を照合 |
| **新しい研究SQLiteの合計** | **115河川・176,777河川文脈記録** | GitHub Actionsで生成・検索・整合性・SHA付き3分割復元を成功 |
| 九州のコード未確定B判定（作業前） | 115,062河川文脈記録・92河川名×水系ペア | 元原本の河川名復元済み |
| 同じ九州でコード未確定の残り | **93,441河川文脈記録** | 確定データへ勝手に合算しない |

**単位に注意：** 408,036件は分類×地方×水系×年度×掲載名の旧集約キー。176,777件は河川×年度×掲載名等に復元した**河川文脈記録**。新しい生物採集件数や分類学上の種数ではない。元の旧キー408,036件、復元キー679,478件はこの実装でも変わらない。

## 九州の一次・独立資料

- [国交省「河川の情報図」九州の配布機関一覧](https://www.mlit.go.jp/river/hourei_tsutatsu/riyou/kasen_riyou/oudan/kyuushuu.html)：**20水系・87個別河川名掲載ペア**（HTMLの実測）。各水系に関連する河川名は分かるが、**10桁河川コードは載っていない**。
- [気象庁 2026-04-22「指定河川洪水予報の対象河川」等](https://www.data.jma.go.jp/suishin/oshirase/pdf/20260422.pdf)：九州に関連する10桁河川番号の掲載を独立検証。原典PDFのSHA256は`1fd72d7aaca4c42292249012de4dee03e0fa2e40554ac55b33ab12e306bb3275`。
- [国交省 全国河川コード一覧](https://nlftp.mlit.go.jp/ksj/gml/codelist/RiverCodeCd.html)：10桁コード・水系・河川名の既存標準データ。水系域コード上位6桁によって所属水系を参照。

**判定の厳格な条件：** 気象庁の予報区域名が単なる河川名そのものであること（「水系」「上流部」「下流部」「五ヶ瀬川・大瀬川」のような区域名は除外）。同じ行の10桁河川番号と全国コード表の名前が完全一致。さらに、国交省の独立資料でも河川名が該当水系に掲載され、全国コード表の水系内同名コード候補が1つだけ。元生物調査原本の地整が「九州地方整備局」で、既存研究キーのB判定であることを照合する。

先頭2桁から所在地県を類推しない。同名別河川を統合しない。流路の階層や直接合流は未確認。「水系」の過去調査を「個別河川で確認された生物」へ昇格させない。

## 「名前だけ」検証した部分と未完了

別系統のMLIT公式配布機関資料では、B判定のうち**42河川名×水系ペア・60,673河川文脈記録**が、正式な水系と河川名の組合せとして裏づけられた。このうち10桁コードを独立確認できた9河川は今回Aに昇格。

残るものは独立した10桁コード根拠がない限りB判定のまま。特に水系内に同じ河川名で複数のコードがある場合は、名前の一致では確定できない。**認証前のBをA件数に含めない**。

国土数値情報の旧河川GIS（W05）にも10桁コードが収録されるが、当該データの使用許諾条件は「非商用」。収益化を行うつりくえ！への転用リスクがあるため、**W05を取得・複製・組み込みせず**、許諾が確認されるまで商用データソースとして採用しない。

元の本番MySQL実数、詳細地点、都道府県との対応、個別生物種の分類学的な厳密な判定は未確認。
