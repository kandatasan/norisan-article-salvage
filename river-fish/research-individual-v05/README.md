# 日本の河川大図鑑：河川名ファースト生物調査DB v0.5

2026-10-20｜研究ブランチ：`research/river-biota-name-first-20261020`

## 方針転換

読者が求めるのは河川番号ではなく「この川で記録された生き物」。
図鑑画面の目標は **都道府県 → 水系（生物表示なし） → 河川 → 魚類／底生動物／鳥類／植物の4窓**。

**河川コードの有無は掲載の必須条件としない。** 公式生物調査原本の地域・地方整備局・水系名・「河川名」欄で、資料上の個別河川名を識別できる場合は、コードなしのまま別の河川名IDで整理する。既存の10桁確定コードは保存する。正確な地理的位置・市町村・都道府県は推測しない。

旧 v0.4 SQLiteをSHA256で検証してから新しいSQLiteを**別ファイルへ読み取り専用複製**し、`name_first_rivers` と `name_first_context_links` を増設した。これまでの河川コードA/B/Cクラス、出典、年度、生物掲載名は変更していない。新旧の判定は異なる軸であり、A/B/Cを単純に書き換えない。

### 採用・保留ルール

**表示候補（コードなし可）**

1. 国交省の生物調査原本に、*魚類／底生動物／鳥類／植物*の対象分類、調査年、元資料記載名、水系、河川名が明示される。
2. 河川の識別IDは **地方区分＋調査機関の地方整備局＋水系名＋原本記載の河川名** から作る。10桁コードは分かるものだけ併記。単に同じ「中津川」という理由で別水系・別管轄を統合しない。
3. 水系名のみの記録（河川名欄空欄）は河川では表示しない。
4. 個別河川の記録と、水系全体の過去記録は独立して保持。採集地点詳細、座標、出現個体数を新規公開しない。

**保留（47件）**

- 全国コード台帳で、同じ水系・河川名に別々の河川コードが複数あるもの：**41件**。コードを不要としても、複数の物理的河川の可能性を原本情報だけで解消できないため慎重に保留。
- 湖やダムなどを「川」と誤認するもの：3件。
- 「旧」や「本川下流」など括弧つき・区間名・複数河川名の合成：3件。

保留は捨てずに `outputs/name_first_held_for_review_v05.csv` へ記録し、後日、公式資料の文脈が明確になれば審査できる。

## データ／プログラム

- `build_name_first_v05.py`：v0.4の全件を保持しながら新しい識別ID・出典付き表示用VIEWを生成。
- `name_first_detail_v05.py`：**水系と河川名（または識別ID）だけで**4分類の記録数・年度範囲・記載名・出典を返す読み取り専用検索。コード任意。`--list-rivers` で水系内の河川名を取得。
- `test_name_first_v05.py`：同名河川の地域・水系区別、湖・ダム・調査区間名の保留を検査。
- `snapshot_parts_v05.py`：別の研究用SQLiteをSHA256付き3分割保存・再展開して検証。
- `outputs/name_first_rivers_v05.csv`：検索対象428のID・水系名・河川名・任意コード・記録件数。
- `outputs/name_first_by_region_v05.csv`：地方別コードあり／なし件数。
- `outputs/name_first_held_for_review_v05.csv`：保留47件と理由。
- `outputs/name_first_audit_v05.json`：全件監査・元データとの件数一致。
- `outputs/kyushu_homangawa_name_first_example_v05.json`／`outputs/chubu_mibugawa_name_first_example_v05.json`：河川コードなしでも4分類を返せる実検索結果。
- `outputs/kyushu_chikugogawa_river_list_v05.json`：水系別の河川一覧の実検索結果。
- `outputs/river_individual_research_v05.sqlite.gz.part000`～`part002` と `outputs/snapshot_parts_v05.json`：実際に再構築可能なSQLite本体。

- **都道府県→水系**の紐付けは今回も未実装。全国コードの先頭2桁から県を導出しない。県境をまたぐ川・水系に注意。

- 428河川名IDのうちコードなし313件の地理的同一性を、必要に応じ現行の公的河川資料で確認する。DBの原本名称だけで正確な県、直接の合流先を断定しない。
- 表示UIは指定の **都道府県→水系→河川→4窓** が方針。UIはまだ実装していないが、データAPIが返す4分類は完成。水系に生物記録を混在させない。
- 47保留件はソースから再調査し、公開前に重複・区間名・湖沼などの個別レビューを行う。
