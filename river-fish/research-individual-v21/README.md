# つりくえ！全国河川魚類図鑑 v0.21｜47都道府県・公式川名／水系名ディレクトリ

2026年10月20日。**研究版のみ。GitHub main、本番WordPress・API・DBには反映しない。**

## 何を増やすか

魚図鑑v0.20の「調査資料に紐づく511河川名グループ」を保持したまま、既存の都道府県公式ページなどで確認した河川名／水系名を別の名前検索枠として統合する。出典別の名称レコードがあることと、その川で魚を採集した記録があることは別。

- 収録源：旧v1.3の北海道等10道県・v1.4の32都府県・中国地方の二級水系／山口県／広島県の既存原資料名と、新たに公式HTMLで確認した群馬県の川名9件。
- 47都道府県の入口で名前を選べることを目標とするが、**県の全河川を網羅したとはいわない**。
- 「river」は資料の河川名、「watershed」は資料の水系名。**水系名を一つの河川種・支流そのものとは扱わない**。
- 水系欄が原典にない川は「水系未確認（公式資料の川名）」にまとめ、憶測で所属水系を割り当てない。
- 県・水系・川名が同じレコードは画面上ひとつの*掲載名グループ*にまとめ、複数の出典IDはすべて保管する。行政上の同一河川や同一区間を同定した意味ではない。
- 元の511グループ・魚の種類名639件・星（レア度349／味160）・調査方法の差は変更しない。

## 画面上の新しい区別

魚の調査記録に接続済みの川は従来どおり魚カードを表示。

公式資料に川名のみ確認できたものは、県→水系→川名で選択でき、出典URLに加え**「魚類の調査記録は未接続。魚がいないという意味ではない」**と表示する。

公式資料に水系名のみ確認できたものも、その名称を閲覧可能にするが、川や魚の調査確認と混同しない。

元の**195所在県未確定**グループは、同じ川名が県の資料に見つかっても自動で県を埋めない。完全一致する「水系＋河川名」は、別CSVの**同一性未承認候補**としてだけ保存する。

## データ権利・一次資料

既存v1.3/v1.4/v1.0の公式出典URLは、各出典レコードに保存する。
例： [青森県・西北管内の河川](https://www.pref.aomori.lg.jp/soshiki/kendo/go-kendo/kasen.html)、[山口県の洪水浸水想定区域河川一覧](https://www.pref.yamaguchi.lg.jp/soshiki/132/277948.html)。

新たな群馬県9件： [群馬県の一級河川一覧](https://www.pref.gunma.jp/page/11219.html)、[河川の現況](https://www.pref.gunma.jp/page/11180.html)。

公開前には商用利用・第三者著作物・出典表記・改変表示条件を個別に確認する。希少種地点の詳細情報は追加しない。
