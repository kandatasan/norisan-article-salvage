### 山口県2026年の河川・市町村表

[山口県「洪水浸水想定区域の指定・公表状況について」（2026-05-29更新）](https://www.pref.yamaguchi.lg.jp/soshiki/132/277948.html) の冒頭部分の公式HTMLをもとに、3水系から**81件の河川名・関係市町の掲載情報**を抽出。

- **佐波川水系：33行**（山口市15／防府市14／周南市4）。
- **小瀬川水系：8行**（岩国市3／和木町5）。
- **錦川水系：40行**（岩国市31／周南市9）。

この81行は資料の**部分的な抽出**であり、山口県全管理河川の網羅リストではない。同一河川が複数市町に載る場合もあるため、**81本の異なる川を新規同定したわけではない**。

また、原資料の「関係市町」は川の全流路を示すものではない。掲載された浸水図の「2025年6月3日」「2026年3月24日」は**浸水想定区域の公表・告示に関する日付**であって、魚類の現地調査年度ではない。

- 例：**佐波川水系の「三谷川」**は山口市・防府市の2市に掲載。1河川の全区間とも、別の同名河川とも自動判定しない。
- 例：小瀬川水系の「駒ヶ迫川」を和木町の出典掲載行として扱う。
- **錦川水系の川に国の水系別魚類記録を勝手に割り当てない**。

### 登録方式

- `chugoku_second_class_watersheds_v10.csv`：4県72件の水系掲載事実。旧広島の15水系は既存台帳から別の出典・分類で取り込む。
- `yamaguchi_river_municipality_mentions_v10.csv`：県の最新ページに出た水系、河川名、関係市町の81掲載行。10桁の河川コードは未照合。
- `chugoku_registry_v10.py`：既存の47都道府県DBに2テーブルを追加し、県・水系・川名・関係市町から探せるSQLiteキャッシュを生成。
- `test_chugoku_registry_v10.py`：同名の川が複数自治体に掲載される場合と、魚種・国の河川コードの誤帰属を防止する14件のテスト。

```bash
python river-fish/chugoku_registry_v10.py --build --db /tmp/chugoku-five-pref-v10.sqlite
python river-fish/chugoku_registry_v10.py --db /tmp/chugoku-five-pref-v10.sqlite --prefecture 山口県 --river 三谷川
python river-fish/chugoku_registry_v10.py --db /tmp/chugoku-five-pref-v10.sqlite --prefecture 鳥取県
python river-fish/chugoku_registry_v10.py --db /tmp/chugoku-five-pref-v10.sqlite --prefecture 山口県 --watershed 小瀬川 --municipality 和木町
```

### 次の工程

1. 4県の**全河川名**の独立した一次資料を取得して追加する。県の公表PDFはExcel/HTMLと異なり、表構造・文字化けや利用許諾を個別に検証。
2. 5県の地理的な国の10桁河川コードとの同一性を、県の確認資料や現況資料で承認。**名前だけで統合しない**。
3. 小河川の実際の魚の観測資料が見つかったものだけ、個別の魚種記録を追加。希少種の位置を出さない。
4. 商用サイトでの一括公開前に出典表示・利用条件を監査し、WordPress検索UIを試作する。

今回は情報源から川／水系の名称という事実を抽出しただけで、元PDFの文章・地図・写真・GISデータは取り込んでいない。旧W05非商用データを利用していない。
