# 全国河川魚類図鑑 v0.22｜川名資料から魚の調査記録へ安全に案内する

2026-10-20／研究限定。**WordPress・公開API・本番DB・GitHub mainには反映しない。**

## 新しい体験

**都道府県 → 水系 → 河川名 → 魚の調査記録**の操作を分かりやすくするため、v0.21の公式掲載名のうち、既存の魚調査グループと「県名・水系名・河川名」が完全一致する**検索候補だけ**を参考リンクとして表示できるようにする。

この一致は**同じ物理的な川・区間の確認ではない**。川名の重複や越県流域があるため、別々のデータを自動合体して魚を割り当てない。参考リンクのボタンを押すと、もともとの魚調査画面に移動し、元データで区別した「過去調査／環境DNA」、記録年、出典リンクを表示する。

- 公式資料だけの川は常に「魚の記録は未接続」。魚がいないとは表示しない。
- 川のセレクトで「【魚記録あり】」「【川名資料・魚未接続】」「【水系資料・魚未接続】」を表示し、魚調査入口を先頭に並べる。水系資料だけを川の観測記録として扱わない。
- **195所在県未確定グループは県未確定のまま**。同一文字列を見つけても新たな県や河川コード・合流先を断定しない。
- 元の511魚調査グループ／1057公式名称グループ／639の魚原資料記載名／星／12件の一言メモ部分照合／9件の規制フラグは保持。

## 出力

- `outputs/river_fish_navigation_and_review_v22.zip`：ローカルHTTPで操作できる研究版
- `outputs/same_name_fish_record_references_v22.csv`：名称完全一致の根拠・参照先・未承認ステータス。地理的な同定表ではない
- `outputs/same_name_navigation_qa_v22.json`：元の件数維持と非自動結合の検証
