# つりくえ！ UX中古車相場ツール v0.7：一般中古車を基準に変更

## 目的
UX記事の途中でグレード・年式・走行距離・カラーから「大まかな参考価格帯」をサクッと見られるツール。相場の下に、ガリバーで未公開車両の相談をする導線を設置する。未公開車両が必ず安い、必ずあるという保証はしない。

## 最新変更
- **レクサスCPOを価格集計から除外**。一般中古車のみを使うために `market_segment=general_market` と `excluded_segments=["lexus_cpo"]` を検証。
- 現時点は一般中古車の13件の予備的な観測から2種類の価格帯を試算。年式・グレードをずらして推定値に見せかけない。
- 年式は1年単位。走行は1万km単位で指定するが、指定帯のデータが足りない場合に同年式・同グレードの横断集計を表示するときは、その違いを明記。カラー差は未補正。
- 参考価格帯は下位25%点～上位75%点を10万円刻みに外側へ丸めたもの。中央値併記。
- 価格は支払総額（税込、基本プラン）で比較。修復歴あり・レクサスCPOは除外。地域・保証・装備の差は未補正。

## 安全な表示ゲート
価格JSONでは `publication_reviewed=false`、`research_preview_only=true` に設定。公開サーバーでは金額を表示せず **「集計中」** とする。
限定された試算値はローカルの `http://localhost:PORT/index.html?preview=1` のみで表示する設計。
ガリバーA8の既存自由テキスト素材、広告開示、申込時に連絡先入力が必要という注意書きは維持。

## 公開までの課題
1. 一般市場のサンプルを増やし、モデル×年式×グレード別に偏りを減らす。1万km帯に価格を出せない場合は、実際の集計範囲を示す。
2. サンプルの重複、掲載継続、グレード、修復歴を再検査する。
3. グーネット・カーセンサー等の規約を遵守し、無断の機械的自動取得・掲載一覧の商用複製をしない。参考調査と独自統計の公開条件を確認する。
4. iPhone/Safari表示、広告最終遷移先、WordPressの挿入位置を検証する。
5. 既存PRはドラフトのまま。mainへのマージ、WP/Xserver反映は未実施。

対象のPRは #867。河川図鑑の静的ファイル配信や、ほかのWordPress記事には触らない。
