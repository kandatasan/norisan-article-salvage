## 星の定義

- **レア度（★1～5）**：魚に合う環境で釣りや観察をする場合、一般的に出会いやすいかを編集上の感覚で比較。**絶滅危惧区分・全国の個体数・都道府県別の希少度ではない。**
- **味（★1～5）**：適法・適切に処理され、食材として扱われる場合の一般的な食味の評判。**採捕・運搬・調理・食用の可否と安全性を示さない。**食文化が確認しにくい魚に無理に★を付けない。
- **味が未評価**は「まずい」「食べられない」の意味ではない。フグ類・キタマクラなどは安全性の問題から採点対象外。別名・種名未確定等26件はレア度も味も対象外。
- 星の数は**公的資料が定めた評価ではない**。個別の希少性・調査地点・レッドリストの区分と混同しない。

## 研究版の生成

```bash
python river-fish/research-individual-v19/build_evidence_v19.py
python river-fish/research-individual-v20/build_general_stars_v20.py
```

SHA照合の後、`outputs/river_fish_general_editorial_stars_v20.zip`、全375候補の`fish_general_star_coverage_v20.csv`、`fish_general_star_qa_v20.json`を生成。GitHub Actionsでは別処理でCSV・ZIP・HTML JS・レコード数を再点検する。

味★の追加根拠は「食文化・一般的な食味の印象」であり、食品衛生や魚種同定の検証ではない。フグの素人調理は避ける（厚生労働省：https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000094363.html）。
