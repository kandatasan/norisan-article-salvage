公式の国土交通省河川水辺の国勢調査における過去の水系×年度×掲載名を表示する独立プラグイン。
専用DBのみ、管理者が手動でデータ取込後に利用可能。旧版は保持し復元可能。
設置ショートコード：[tsurikue_biota_search]

本番WordPressでの実機確認・バックアップ・権利表記の後にのみ公開可。
国交省公式一覧 https://www.nilim.go.jp/lab/fbg/ksnkankyo/dl_00_index.html
国交省利用ルール https://www.nilim.go.jp/lab/fbg/ksnkankyo/Mokj_chui.htm
掲載記録数は種数ではなく、個別河川や現在の生息を証明しません。
