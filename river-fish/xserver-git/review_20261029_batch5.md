# 河川魚類接続レビュー 第5便（2026-10-29）

対象は既存の未接続河川名グループのみ。河川名グループの追加・削除・統合は行わない。

## 採録

- 茨城県の公的資料5点を確認し、8既存グループ、魚名24件を接続候補化した。
- A「魚類調査記録」は久慈川、那珂川、鬼怒川、利根川、大北川、桜川、恋瀬川の7グループ18件。
- B「資料に掲載された生息魚」は十王川の1グループ6件。
- 調査年は単年を確認できた久慈川・那珂川・鬼怒川・利根川（2025年）、大北川（2024年）、桜川（2012年）のみ数値化した。
- 恋瀬川は1996～2002年の調査期間を資料名・根拠要約に保持し、単一年へ置換していない。
- 既存グループの「水系未確認（公式資料の川名）」は変更せず、水系を推定補完していない。

## 保全・同一性審査

- 検査結果表にある市町村・字・ダム名以下の採取場所は公開データに収録していない。
- 十王川は整備計画が生息確認済みとする一般魚6件だけを採録し、同じ段落の重要種は除外した。
- 桜川は県環境科学センターが「本日観察した魚類等」として列挙した魚名だけを採録した。
- 恋瀬川は県水産試験場報告が採集個体数上位として明記する5件に限定し、`ヨシノボリ属`を確定種へ置換していない。
- 同名河川の取り違えを避け、茨城県の既存河川名グループIDだけを接続対象とした。

## 保留・除外

- 涸沼川圏域の「ほとんどの河川」に関する魚名は涸沼川本川へ割り振らず、C相当で保留した。
- 小貝川圏域の圏域一括魚名は、小貝川・谷田川・八間掘川等の個別河川へ割り振らなかった。
- 漁業権対象魚、遊漁規則、放流・増殖情報は生息確認として扱わなかった。
- 十王川整備計画の重要種、恋瀬川報告の希少種と詳細調査地点は公開接続から除外した。
- 牛久沼の検査記録は既存の河川名グループに一致しないため、今回の分母へ追加しなかった。

## 集計境界

- 第4便反映後の接続数は437／1,127グループ（38.78%）。
- この8グループがmainと隔離テスト環境に反映された場合は445／1,127（39.49%）。50%の564グループまで残り119グループ。
- 本番公開、WordPress、biota APIには反映しない。
