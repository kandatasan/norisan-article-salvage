# 生物図鑑 v2.1 — 植物・鳥類などの公式資料候補の安全な一覧化

2026-10-18。**URLインベントリの準備作業のみ。WordPress・生物調査DB・公開サイトの変更なし。**

## なぜ今これをするか

v1.9で魚類・底生動物の全国9地方の水系年度調査は導入済み。一方、植物・鳥類・両生類/爬虫類/哺乳類・陸上昆虫類等は2025年の「分類名簿」しかなく、各水系での過去の観測結果をまだ持たない。

国交省の河川版ダウンロード一覧には、上記項目の「確認種一覧」の入口がある。しかし ZIP のURLやファイル名の略称だけで、生物区分・Excel列・年・観測粒度を勝手に決めるのは危険。

## 今回の機能

- 国交省 https://www.nilim.go.jp/lab/fbg/ksnkankyo/dl_00_index.html の **HTMLだけ**を取得。ZIP原本・調査の観測行はダウンロードしない。
- ダウンロード一覧の公式直接リンクから、地域コードRT81〜RT89を持つ標準ZIP候補を一覧化。
- v1.9でハッシュと列が検証済みの底生動物9リンクのみ、既知の底生動物資料と分類。
- それ以外の候補は **生物区分＝未審査（null）**。植物や鳥類であるとURL文字列だけでは断定しない。
- GitHub Actionsで添付する JSON はURL・状態だけ。希少種地点、GIS、緯度経度、種名、Excel本文は保存しない。
- 国交省のドメイン・公式インデックスとの一致、既知底生動物ソース9件の包含、9地方すべての候補があることを厳格にチェック。

## 次の実作業

1. 未審査候補の各ZIPについて **公式一覧上の列位置・カテゴリ見出しと紐付け**を検証。
2. ZIPの公式URL、実ファイルSHA-256、内部のExcelファイル名、先頭行の見出し、厳密な「生物項目」表記を審査・固定。
3. 魚類・底生動物と同じく「地方×水系×調査年度×資料上の名前」だけ独立取り込み。各カテゴリの元原表に存在しない情報は埋めない。
4. 生物分類参考リストの属・種コードへの同定、所在地県・支流へのリンク、保護対象生物の詳しい場所は別審査とする。
5. 3方向検索v2.0へ新しい各調査テーブルを追加する段階でも、名前分類・生息分布を誤結合しない。

## 安全境界

元データに明示のない県・河川を推測せず、URLだけでカテゴリを付与しない。2025年の分類名簿37,648掲載行を地域調査の証拠として扱わない。WordPress本番・GitHub以外の対象へ書き込まない。
