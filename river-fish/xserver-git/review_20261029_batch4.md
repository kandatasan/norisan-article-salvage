# 河川魚類接続レビュー 第4便（2026-10-29）

対象は既存の未接続河川名グループのみ。河川名グループの追加・削除・統合は行わない。

## 採録

- 群馬県の公的資料6点を確認し、7既存グループ、魚名10件を接続候補化した。
- A「魚類調査記録」は利根川、吾妻川、広瀬川、谷田川、赤谷川、鶴生田川の6グループ6件。
- B「資料に掲載された生息魚」は烏川の1グループ4件。
- 調査年は資料から確認できた利根川（2026年）、吾妻川・赤谷川（2023年）、鶴生田川（2017年）のみ記録した。
- 市町村以下の採捕場所、詳細区間、放射性物質の検査値は収録していない。
- `トウヨシノボリ` を含め、資料の魚名を現在の分類へ置換していない。

## 保全・同一性審査

- 群馬県動物レッドリスト2022年改訂版と2024年部分改訂の公開状況を追加確認した。
- ヤマメ、イワナは資料上の採捕河川名だけを収録し、市町村内の採捕場所は非公開とした。
- 烏川は整備計画で一般魚として列挙された4件だけを採録し、同じ節の重要種は除外した。
- カネヒラは整備計画が鶴生田川の平成29年度調査確認として明記する河川単位記録のみを採録した。
- チャネルキャットフィッシュは外来種であることを別種へ置換せず、群馬県水産試験場が明記する谷田川の採捕記録として扱った。

## 保留・除外

- 利根川中流圏域の「利根川、広瀬川合わせて30種以上」は河川別の魚名対応がないためC相当として保留した。
- 渡良瀬川圏域、吾妻川圏域、利根川上流圏域の圏域一括魚名は個別河川へ割り振らなかった。
- 漁業権対象魚、遊漁規則、放流・増殖予定は生息確認として扱わなかった。
- 片品川水系支流の特殊斑紋イワナは片品川本川へ割り振らず、保全上も公開接続から除外した。
- 河川水辺の国勢調査の実施河川一覧だけで魚名がない片品川、渡良瀬川等は接続していない。
