# つりくえ！｜日本の河川魚類図鑑 v0.15（魚類先行・研究試作）

2026年10月20日。ユーザーの方針決定：「**魚だけを先に完成。魚の名前＋レア度☆5＋味☆5＋一言メモ。都道府県→水系→河川で探せる。底生動物・鳥類・植物は後で追加**」。

## 画面の第一完成形

- 都道府県／所在県未確定の資料 → 水系 → 河川・支流。
- 選択河川に記録された**魚類の資料上の掲載名**のカード一覧。魚名を検索、40件ずつ表示。
- 魚カードの優先表示：**生物名／レア度（星5）／味（星5）／一言メモ**。
- 元資料が示す区分で**過去の調査記録／環境DNA検出**を小さく明示。DNAだけで魚の捕獲・目視としない。
- 出典は画面上、代表1件のみ見せる。魚カードの「出典を確認」から**実際に参照した全ソース**を辿れる。表示簡略化と根拠保持を両立。
- 収録魚類名がない河川には「現在この河川名の収録調査記録はない」と表示し、**生息していないと断定しない**。

## 既存データを破壊せず魚を先行させる

`build_fish_first_v15.py` は、SHA256で実物照合したv0.12 ZIPをソースとして魚類JSONだけコピーする。環境DNAの元JSONは**魚類だけにフィルタリング**し、昆虫・鳥・植物のDNAを魚に混ぜない。v0.12原本・他生物データは残したまま、新しい**魚類専用ZIP**を作る。

魚種の星・味・一言メモは、河川ごとに作らず共通魚種マスターに格納。照合キーは**資料記載名の完全一致**であり、分類群名・属名・「アブラハヤ/タカハヤ」などの未同定名を勝手に独立した確定種に分割・同定しない。

- `fish_editorial_reviewed_v15.csv`：編集者が根拠・評価者とともに記入する、承認済み評価CSV。**初期状態は見出しのみ**。星や魚の食味を推測で埋めない。
- `fish_master.json`（生成物）：元資料に実在する魚名の集合。未審査レア度・味は`null`、一言メモは空欄。「未評価」と表示。レビュー後に魚種の共通情報が川別カードへ反映される。
- レア度は**全国的な珍しさのつりくえ独自編集評価**。川ごとの目撃頻度ではない。味は独自・主観評価であり安全性や捕獲権利の保証ではない。保護／センシティブ魚名は食味評価を禁止する入力バリデーションがある（自動希少種判定ではない）。
- 保護種の情報は今後の正式な監査でさらに慎重に扱う。位置が絞れる具体的な地点はもともと含めないが**河川名まで公開してよいかも公開前に審査**。

## 研究範囲と今後の本番対応

現時点の基礎は511の**資料上の河川名グループ**であり、511本の相異なる川、511河川の魚存在、または全国河川網羅とは主張しない。全魚種完全網羅を達成したと主張しない。魚名の同物異名・分類学チェックは別途必要。

公開前に商用再利用の許諾・第三者権利・保護種の位置情報・品質と実機操作を確認。本番WordPressのプラグイン／API／DBには**現段階では書き込まない**。

研究HTML・CSVはこのブランチで検証し、Actions成功後に研究基点ブランチへ統合する。

### 試作の起動

`outputs/river_fish_first_static_preview_v15.zip` をダウンロードし、解凍した場所で `python -m http.server 8000` を実行。ブラウザから `http://localhost:8000` を開く。ローカルファイルの直開きではブラウザのセキュリティ制約でJSON読み込みが止まることがある。

### 次に埋める作業

**魚の共通編集マスターのレビュー**（レア度・味・一言メモ）→河川名の重複・法定区間の照合→公開可能な商用データのみ選別→iPhone・PCで確認→魚類図鑑を第一公開版にする。底生動物・鳥類・植物はこれらの後に拡張。
