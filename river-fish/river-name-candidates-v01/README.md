# 河川名候補レイヤー v0.1

既存河川図鑑の魚類接続率50%計画と、将来の河川名拡張を分離して管理する研究用台帳です。

## 固定する数字

- 50%計画の固定分母: **1,127河川名グループ**
- 2026-11-04時点の接続済み: **477グループ（42.32%）**
- 50%到達条件: **564グループ接続**
- 残り: **87グループ**

このフォルダの候補は、河川名が公式資料に掲載された事実だけを保持します。候補を追加しても固定分母、接続済み数、公開済み数は変えません。

## v0.1の候補

広島市公式ページからリンクされた「広島市域内の河川（令和6年4月1日現在）」の地図で、文字として明確に読み取れ、現行 `atlas.json` に広島県の同一名グループがない22名称を収録しました。

- 候補数: 58
- 公開検索への追加: 0
- 個別静的URLの生成: 0
- 魚類接続: 0
- 水系・河川コードの補完: 0

「河津川」「高山川」は現行図鑑に別の都県・資料文脈で同名があるため、同名候補数を記録し、自動統合しません。

第2波では、仙台市公式「仙台市の河川」に掲載された44名称を既存図鑑と照合しました。既に同じ河川または宮城県の同名グループとして収録されていると判断できる8名称（名取川、広瀬川、笊川、新川、坪沼川、支倉川、碁石川、本砂金川）は候補へ重ねず、残る36名称を追加しました。

「梅田川」「高野川」「堀切川」「山田川」は現行図鑑に他都府県等の同名文脈があるため、自動統合しません。公式一覧に水系見出しがある場合も、この候補台帳では河川同一性の昇格審査が終わるまで水系列へ転記しません。

## 昇格条件

候補を本体へ追加する前に、少なくとも次を別途確認します。

1. 都道府県・市区町村・河川名の同一性
2. 同名異河川の分離
3. 水系名を付ける場合は、その水系を明記した根拠
4. 河川コードを付ける場合は、個別河川との同一性を示す根拠
5. 魚類を付ける場合は、対象河川そのものに対するA/B根拠
6. 希少種の詳細地点や非公開情報を含まないこと

昇格前は `research_only_not_published` のままにし、`river-fish/xserver-git/source/`、WordPress、biota API、サイトマップへ流しません。
