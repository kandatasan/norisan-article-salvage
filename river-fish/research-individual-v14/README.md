# 日本の河川大図鑑｜鳥取県の公式河川台帳 v0.14（研究専用）

2026-10-20 / **本番WordPress・公開API・公開図鑑は変更しない。**

## 実証した取得結果

鳥取県河川課が公表した「鳥取県 河川一覧」（**2023年4月1日現在**）の3PDFを実際にGitHub Actionsで取得し、PDFのヘッダー・日付と河川名の各行を検査。PDF原本そのものは本リポジトリに再配布していない。

- [東部](https://www.pref.tottori.lg.jp/secure/1313532/toubu.pdf)：**141掲載行**。PDF SHA256 `d04b8a4e89b9a41a20e415e0682848eef397bcee7bab182eaf3472ba077f47b4`
- [中部](https://www.pref.tottori.lg.jp/secure/1313532/230401chubu.pdf)：**112掲載行**。PDF SHA256 `92ad51661b8ceaca84d932251151ddb3fbeb3ca2c5705b4e4cdacba3ba539af4`
- [西部](https://www.pref.tottori.lg.jp/secure/1313532/230401seibu.pdf)：**121掲載行**。PDF SHA256 `a73c577608046a91aa54315f43246aa1e83190712e16831544e807ed04a3c6d5`

**合計374掲載行、331の固有河川名表記**を抽出。これは**全国511河川名グループへ331河川を追加したことではない**。同じ河川名が複数管理区分・資料に載る可能性があり、1本の物理河川を認証するための測量・照合は未完成。県による管理河川の「資料名」です。

### 水系の扱い

PDFの水系セルが同じ行に**明示的にある**組合せだけは7組あり、既存511表示名グループと照合して未掲載候補3組を発見。

**残りのPDF河川行は水系を勝手に推定していない**。PDFでは水系欄が縦方向に結合されており、単純なテキスト化でそのまま展開すると誤結合の危険がある。別途、正式な水系×河川名の対応表の再検証が必要。PDFの「番号」はその一覧表の番号であり**10桁河川コードではない**。

### 保存した実ファイル

- `extract_tottori_inventory_v14.py`：3県公式PDFを取得・SHA256計算・PDF行を検証。地名のUnicodeの表記揺れを正規化し、管理区分・河川名・延長・同一行の水系名を列別に保管。
- `outputs/tottori_official_river_source_rows_research_v14.csv`：**374元資料掲載行**、水系が明示されない場合は空欄。生物名・生息確認なし。
- `outputs/tottori_river_inventory_provenance_qa_v14.json`：原本別SHA256／掲載行数／旧511との照合・保留状態。
- `.github/workflows/river-tottori-river-list-v14.yml`：GitHub Actionsで原本を入手してPythonスクリプトの整合性チェック、研究ブランチに保存。

### ライセンスと将来の公開判断

県公式一覧 https://www.pref.tottori.lg.jp/307111.htm 。

[鳥取県の著作権案内](https://www.pref.tottori.lg.jp/9314.htm) では、資料の無断複製・転用を制限し、利用許諾の問い合わせを案内している。このため**本データは研究ブランチ内だけに保持し、商用ブログ・静的図鑑への取り込みは禁止**。掲載名の転載に当たるか、県の明示の許諾が必要かは別途確認する。非商用の国土数値情報W05は使用していない。

今後の全国制覇に向け、都道府県単位の公式台帳をこの方式で照合し、水系と地点が確認できて権利が整理できたデータから段階的に利用する。
