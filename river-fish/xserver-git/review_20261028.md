# 河川魚類接続レビュー（2026-10-28）

対象は main の `atlas.json` にある既存の河川名グループのみ。水系名のみの441件、既存データの外にある資料掲載名16件は分母・新規接続数に含めない。河川IDの新設・統合はしない。

## 着手時の実測

- 魚類調査系の河川名グループ511件のうち、魚名あり352件（`river_fish_label_counts_v25.json`）。
- 川名のみ616件のうち、既存の `fish_source_connections_v01.json` が接続するもの22件。既存25件の対応IDのうち、残る3件は魚類調査系のため重複加算しない。
- 分母1,127件、分子374件、33.19%。50%には564件以上が必要。
- 本番・ci-preview の4代表ファイル（atlas、魚名件数、追加資料v01、index）はそれぞれ同一SHA-256。作業開始時のci-previewは本番と同じ静的データ。

## 今回の審査と追加

- 採録審査の対象資料23点を確認。A/Bとして接続候補にした資料19点、27既存グループ、魚名84件（A 55、B 29）。東北・関東・近畿・中国の4地方、5都府県にまたがる。
- Aは青森県の図3（旧十川、十川）と大阪府の和田川調査結果表。Bは大阪府の百済川、広島県の岡ノ下川・二河川・堺川・太田川・小瀬川、山口県の佐波川。各行の原資料名、発行者、URL、表・節、資料表記の魚名、年が確認できた場合の年、要約、同一性・保全・公開状態は `source/data/fish_source_connections_v02_additions.json` を参照。
- 太田川水系の支川三篠川・根谷川・滝山川は、[国交省の整備計画（資料p77–78）](https://www.cgr.mlit.go.jp/ootagawa/plan2/plan2pdf/03plan2.pdf)の各支川の節に明記された魚名をBで追加。希少種や詳細地点の情報は収録しない。古川は同じ整備計画に記述があるが、既存データに魚名があるため新規接続に数えない。
- [広島県の瀬野川水系計画（資料p13）](https://www.pref.hiroshima.lg.jp/uploaded/attachment/554947.pdf)では熊野川の段落から一般的な魚2件をB、[江の川本川ブロックの環境説明](https://www.pref.hiroshima.lg.jp/soshiki/99/1172196461943.html)では本川中流域に明記された魚4件をBとして追加。両資料の支川や水系全体へ魚名を配分しない。
- [山口県水産研究センター研究報告第7号（資料pp77–82）](https://www.pref.yamaguchi.lg.jp/uploaded/attachment/197780.pdf)は錦川で採捕したオイカワとウナギをAで追加（2008年）。検査対象の列挙だけにある魚や放流稚アユは採録しない。
- 青森県[岩木川流域保全計画の図3（資料p24）](https://www.pref.aomori.lg.jp/soshiki/kankyo/kankyo/files/plan10.pdf)で浅瀬石川の欄に記された現地調査の確認魚6件をAで追加。既存の調査由来河川名グループ `rn_51c8995e0adad93e3f85603c` は元の魚名件数が0であり、同名・水系・東北地方を照合。県は原資料による確認とし、元グループに県が確定していたと主張しない。希少種は省く。
- 東京都の[神田川流域計画・表2-5](https://www.kensetsu.metro.tokyo.lg.jp/content/000062580.pdf)から善福寺川のモツゴと妙正寺川の「トウヨシノボリ類」をAで追加。後者の「類」を種へ置き換えない。飼育品種や希少種を除く。
- [黒目川流域計画・表2-2](https://www.kensetsu.metro.tokyo.lg.jp/content/000007284.pdf)は黒目川と落合川の別々の欄の丸印を照合し、それぞれ3魚名をAで追加。[石神井川計画・表2-2](https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/000007328_2)は3魚名、[呑川計画・表2-2](https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/000029221)は2魚名をAで追加。区間情報や希少種は収録しない。
- [目黒川流域計画・河川の生態系](https://www.kensetsu.metro.tokyo.lg.jp/content/000038913.pdf)は河川環境調査等の結果として明示した一般魚4名をAで追加。調査の個別年度が混在するため、各魚名の年は空欄。東京都7グループの元データは「水系未確認（公式資料の川名）」のままとし、資料で確認できる水系名を追加データの別項目に保持する。既存の水系表示を推定で変更しない。
- [柳瀬川流域計画の変更原案・表2-2](https://www.kensetsu.metro.tokyo.lg.jp/documents/d/kensetsu/000058559)で柳瀬川・空堀川・奈良橋川の別々の魚類欄から各4魚名をAで追加。重要種の注記がある魚は除外。東京都の追加は合計10グループになった。
- 基本データの河川名・水系名・県名が完全一致する既存IDにのみ結び、実在する個別河川の地理的な同一性は承認していない。出典にない種への置換、詳細地点、座標は掲載しない。
- 既存273河川詳細ページのIDだけを機械照合してリンク一覧に収録。新しいSEOページは生成しない。

## 検証と反映境界

追加後の分子は401件、401/1,127＝35.58%。50%にはさらに163グループ必要。これは **mainとテスト環境への反映が完了した場合の計算値** であり、PR段階では接続済み・公開済みと称さない。

`validate_atlas.py` は追加行の既存ID完全一致、重複、件数、安全フラグ、詳細ページIDと実ファイルの一致を検証する。GitHub Actionsのステージングのみ利用し、本番用publish/rollback、WordPress、biota APIには触れない。
