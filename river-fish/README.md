# つりくえ！ 川の魚データベース — 公式資料からの初期収録 v0.3

作成日: 2026-10-17。**WordPressや本番DBには未反映**。最初は中国地方5県の公開資料を使う。

## リポジトリに保存したもの

- `curated_fish_records_v03.csv`: **48件**の、資料に魚名が載る水系レベルの記録
- `akaza_local_names_v03.csv`: **12件**のアカザの地方名（広島県内水面漁業協同組合連合会が掲載）
- 県別掲載行数: 広島16／岡山13／島根6／山口6／鳥取7
- 魚名は**30種類の表記**（厳密な30生物種ではない）。例えば「フナ」「フナ類」「コイ類」「スナヤツメ」は種へ勝手に置換しない。

## 大事な区別

1. このCSVは国交省「日本の川」の概説などから抽出した**資料掲載魚名**。正式な「河川水辺の国勢調査」の中国地方確認種CSV原本を取り込んだデータではない。
2. 出典ページに魚名があることと「現地で○年に確認されたこと」は別。調査年が不明の行は空欄とし、公開時に明記する。
3. 天神川の7件は「漁業の対象となっている魚」。放流される魚を含み、独立した野外採集確認の証拠ではない。
4. 地方名の「馬洗川」などは**呼び名の地域**であり、その河川でアカザを採集・確認した地点ではない。魚の地方名検索結果を生息地点に変換しない。
5. 重要種の詳細地点、支流採集地点、座標は公開CSVに保存しない。地域・水系レベルにまとめ、公開可否を別途審査。
6. 魚が登録されていない都道府県・河川は「未収録」。**生息していないとは言わない**。

## CSV の主な列

`prefecture` / `watershed` / `recorded_name` / `evidence_type` / `source_title` / `source_url` / `survey_year`

元の文字表記・出典URL・根拠の種類を優先して残す。検索ページの文言は「○○水系について出典資料に記載」とする。

## v0.4 外来種検索フィルター（2026-10-17）

- `alien_origin_v04.csv`: **水系単位**で根拠を確認できた2件（岡山県・高梁川水系／オオクチバス・ブルーギル）。
- `legal_designations_v04.csv`: **種に対する全国の法令指定**2件。原産区分と法律上の指定は独立して保存。
- `search_v04.py`: 標準和名、地方名、都道府県、水系、外来種区分の検索。Python標準ライブラリのみ。
- `test_search_v04.py`: 在来種・国内外来種を推測しないことを含む10件のテスト。専用の読み取り専用CIを追加（WP操作なし）。

### 実行方法

```bash
python3 river-fish/search_v04.py --name てんきり --prefecture 広島県
python3 river-fish/search_v04.py --prefecture 岡山県 --alien alien
python3 river-fish/search_v04.py --prefecture 岡山県 --alien regulated
python3 -m unittest discover -s river-fish -p 'test_search_v04.py' -v
```

フィルターは `all`（全部）、`alien`（国外＋国内由来）、`foreign`（国外由来）、`domestic`（国内由来）、`native`（在来）、`regulated`（特定外来生物）、`unknown`（未判定）。

**現時点では2種以外の外来種判定は未収録。** 在来と未判定を混同しないため `native` や `domestic` が0件になることがある。0件は実際の不在や分類の否定ではない。

2026年9月1日施行の追加指定は、「オヤニラミ属のうちオヤニラミ**以外**」。オヤニラミ自体を特定外来生物と誤分類しない。2026年9月11日改訂の外来種リストの魚類全件取り込みは**未完了**。

## v0.5：中国地方の公式調査原本から集約（2026-10-17）

国交省の「中国地方→河川版→魚類→確認種一覧」をGitHub Actionsから取得。配布名は RT87_B01.zip、内包ファイルは 魚類_中国.xlsx（Excel）。公式ダウンロード：https://www.nilim.go.jp/lab/fbg/ksnkankyo/dl_00_index.html

### 保存・除外の実績
- 元データ **42,143明細行**。調査年度 **2006〜2023年**。
- **「魚類」28,524行**を水系・年度・魚名の文字列で重複統合し、**2,285レコード・13水系・216名称表記**として出力（厳密な216生物種ではない）。
- 保存: official_chugoku_watershed_year_fish_v05.csv（水系、調査年度、資料記載名、出典URL、公式ZIPのハッシュ）。
- 保存: official_chugoku_manifest_v05.json（SHA-256、収録・除外数、年、根拠）。ZIPが変更された場合は確認まで停止する。
- **旧区分「魚介類」13,619行は混在資料**。魚、エビ、カニ、貝が含まれるため、主データには入れない。
- うち「魚類」区分にも同じ魚名の文字列があるものだけを official_chugoku_legacy_fish_candidates_v05.csv に **1,231候補**として分離。**未承認・非公開・検索対象外**。魚種確定の根拠ではない。
- 元の地点名、地区、距離、座標、日付・時刻、個体数は検索用CSVに保存していない。

### 新しい検索
- search_v05.py は公式調査（調査年度あり）と従来の説明資料（採集年度なし）を**区別**する。
- 名前、地方名、水系、調査年で検索し、結果には出典・データ種別を表示。件数表示とページ分割に対応。
- **都道府県は公式Excelから特定できないので推定しない**。県名フィルター時には県対応の確認済み説明資料だけを返す。
- 外来種／特定外来生物は別の根拠で判定。データがない＝在来／不在、とはしない。

実行例：
    python river-fish/search_v05.py --name アユ --watershed 太田川
    python river-fish/search_v05.py --name ブルーギル --alien regulated
    python river-fish/search_v05.py --name てんきり --prefecture 広島県
    python river-fish/search_v05.py --year 2019 --watershed 江の川 --limit 50
    python -m unittest discover -s river-fish -p 'test_*v05.py' -v

### 公開と品質の制限
- 原本は国直轄など一部の対象河川のみ。特定重要種の詳しい地点は公表対象外。支流を含め全生物分布を網羅しない。
- 216件は「魚名の表記数」。属・類・旧分類・河口の海水魚もあり、厳密な魚種数とは区別。
- 公式資料を加工していることと出典を明記する。国交省の利用条件：https://www.nilim.go.jp/lab/fbg/ksnkankyo/Mokj_chui.htm
- **まだGitHubのデータ・検証コードのみ**。WordPressやつりくえ！サーバーには未投入・未公開。
- 魚種と水系の詳細ページはデータを羅列してSEOページを大量生成するのではなく、人が読んで価値のあるページを優先して作成する。
