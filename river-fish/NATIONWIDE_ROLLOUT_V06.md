# つりくえ！ 全国河川・魚類DB v0.6 — 9地域の公式魚類調査

更新：2026-10-18。**本番サーバー・WordPressには未反映**。全国版の下地とデータをGitHub内で監査中。

## 全国9地域の公式魚類原本を実取得

国土交通省「河川水辺の国勢調査」の [地方別・河川版・魚類確認種一覧](https://www.nilim.go.jp/lab/fbg/ksnkankyo/dl_00_index.html) から、以下9地域のZIP・XLSXをダウンロードして構造とSHA-256を検証。すべて「生物項目」「水系」「調査年度」「種名」の列を確認。

| 地域 | 水系×調査年度×魚名の組合せ | 水系数（地域内） | 旧混合区分・要審査候補 |
| --- | ---: | ---: | ---: |
| 北海道 | 980 | 13 | 636 |
| 東北 | 1,812 | 12 | 1,088 |
| 関東 | 1,587 | 8 | 1,226 |
| 北陸 | 1,539 | 13 | 1,144 |
| 中部 | 2,514 | 13 | 1,539 |
| 近畿 | 2,300 | 10 | 1,316 |
| 中国 | 2,285 | 13 | 1,231 |
| 四国 | 1,849 | 8 | 1,220 |
| 九州 | 3,948 | 20 | 2,468 |
| **合計** | **18,814** | **110（地域別延べ）** | **11,868** |

**18,814は生物種数でも現地調査回数でもなく、地域・水系・調査年度・資料上の魚名の組合せ数。** 同じ川が複数の年度・地域に登場すればそれぞれ集計される。地域ごとに対象や調査期間が異なるので、件数を使って地域の豊かさを比較しない。

旧「魚介類」区分には魚以外のエビ・カニ・貝などが混在する。魚類区分の名称表記との完全一致で抽出した **11,868組合せは審査候補のまま隔離**。公開魚類検索に含めない。

## 配布条件と欠測の扱い

[国交省の公式利用条件](https://www.nilim.go.jp/lab/fbg/ksnkankyo/Mokj_chui.htm) は出典・加工の表示などの条件により商用利用も認める。第三者の権利に注意。重要種の採集地点を特定できるデータは配布対象から除外されている。

この調査がカバーするのは主に**国の管理区間の河川**。二級河川・支流・準用／普通河川まで自動的に網羅するわけではない。魚類登録がない＝実際に生息しない、とは絶対に言わない。

国交省の公式一覧で**沖縄の河川版**は提供がないため、沖縄を「魚がいない」「河川がない」とはせず、県・研究機関資料から別途補う。

## 作成ファイル

- `nationwide_sources_v06.json`：9地域の原本URL、チェック済SHA-256、実ファイル名、正式な調査範囲。
- `japan_prefectures_v06.csv`：47都道府県コード・県名・登録進捗。**河川の網羅性を主張しない**。
- `aggregate_nationwide_region_v06.py`：ソースZIPを確実に照合し、位置情報を保存せず地域別に年度／水系／魚名だけを集約。
- `nationwide-staged/<region>/watershed_year_fish.csv`：調査記録の集約結果。
- `nationwide-staged/<region>/legacy_mixed_category_candidates.csv`：要審査の混合区分。
- `nationwide-staged/<region>/manifest.json`：除外理由、調査年、出典・チェックサム等。
- `search_nationwide_v06.py`：9地域の魚類記録を地域・水系・年度・魚名・地方名で横断検索。県名・支流へ勝手に結びつけない。
- `national_registry_v06.py`：全国47都道府県の登録枠を生成。河川が現時点で確認できているのは広島県の66件のみ、河川名候補98掲載行は別管理。
- 各種 `test_*v06.py`：チェックサム・古い混合区分の隔離・未確認の都道府県・河川への帰属防止を検査。

### 試し方（9地域の集計CSVがリポジトリに登録された後）

```bash
python river-fish/search_nationwide_v06.py --name アユ --limit 20
python river-fish/search_nationwide_v06.py --region chugoku --watershed 太田川 --year 2020
python river-fish/search_nationwide_v06.py --name てんきり
python river-fish/national_registry_v06.py --build --db /tmp/tsurikue-nationwide.sqlite
python river-fish/national_registry_v06.py --db /tmp/tsurikue-nationwide.sqlite --prefecture 広島県
```

**調査時点の集計名を分類学上の現行学名へ勝手に置換しない**。古い名称や属・類・魚介類の混在は、別途分類学的監査が必要。

## 公開サイトへ向けた残工程

1. 河川マスターを47県分に増やす。商用利用可能な自治体・国の台帳から、河川名と水系・親河川の関係を**出典付きで確認**。旧W05非商用GISの無断再利用は避ける。
2. 水系と県の対応を別出典で確認。県にまたがる水系でも、特定県で確認された魚という誤表示を防止。
3. 広島の諸木川などの小河川は、**直接その川を対象とした調査資料がある場合だけ**魚類を紐づける。
4. WordPressに検索API・フロントエンドUIを実装し、情報の薄いページを自動量産せず、利用者価値のある図鑑ページから公開する。
5. 出典・加工の表示、情報更新、法令（外来種）の確認と希少種の保護を運用ルールに組み込む。

**公開リポジトリ上での研究・加工データであり、つりくえ！サイトで公開済みという意味ではない。**
