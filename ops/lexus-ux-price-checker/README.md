# レクサスUX参考価格チェック v0.19 ― 個別グレード公式CPO33台を追加

記事内で3条件（グレード・年式・走行距離）を選び、支払総額ベースの価格帯を**一般中古車／レクサスCPOの2段**に分けて見る軽量静的ツール。MySQL・外部APIは不要。**ツール内にアフィリエイトリンクやPRボタンは置かない。広告導線は記事本文側に別設置する。**

## 本番公開条件
- データJSONの `publication_reviewed` は **true**、`limited_sample_release=true`。掲載例に限定した参考価格として公開候補とする。市場全体の相場と誤認させないよう、少数サンプル・調査日・年式等の不一致を表示する。
- ローカルPCの確認用 `?preview=1` では実サイトの公開制御を迂回しない。公開後はJSONの承認フラグと60日以内の調査日が揃う場合だけ価格を表示。
- 調査用集計は22種類。同じ車両を異なる条件で再集計したものがあり独立22標本ではない。ほとんどの4条件組合せはカバーされていないため、未計算時は「集計中」を表示。
- このブランチではまだ **Xserver専用プレビュー**まで。プレビューのHTTPS一致とWPパーツ確認後、別の安全な本番公開PRを作る。

## WordPress記事用の埋め込み（公開許可後）
```html
<iframe title="レクサスUXの中古車参考価格（一般中古車・CPO比較）"
  src="https://tsurikue.com/ux-price-checker/?model=250h&amp;grade=c&amp;year=2021"
  loading="lazy" referrerpolicy="strict-origin-when-cross-origin"
  style="display:block;width:100%;height:620px;border:0;border-radius:12px"
  aria-label="レクサスUXの中古車参考価格"></iframe>
```
- 記事ごとに URL の `model=250h`、`grade=fs`、`year=2021` などを変更。値はツール内の選択肢で検証される。
- 複数記事で同じ1つの静的URLを共有するため、価格更新はXserver上のJSONを置き換えるだけ。
- WordPress本文の短縮コードやプラグインを増やさず、記事ごとにHTMLブロック1個でよい。
- ツールの iframe URL は検索エンジン向けに noindex。価格データはSEOを目的とした車両一覧の転載ではない。

## 出典・免責
- 数字は掲載支払総額の少数事例による試算。値上がり・値下がり、車両ごとの状態、支払条件等の差を補正していない。
- ツール本体には広告・ガリバーへのリンク・トラッキングピクセルを入れない。広告を掲載する記事では記事本文側でPR表記・リンク先・成果条件を個別管理する。

## 更新・保守
- `python tests/test_release.py` でJSONとHTMLの安全条件を検証。
- JSを別途 `node --check` でチェック。
- 価格データ更新時に出典・掲載日時・CPO区分・重複・集計件数・偏りを監査。年式・グレードの網羅率を確認してから publication_reviewed を変更する。
- 研究用の個票や個人情報は公開リポジトリ・Xserverに置かない。

## v0.17（2026-11-11）グレード混在価格の誤表示を停止
- これまでは個別グレード（F SPORT／標準仕様など）に対し、全グレード混在の参考価格を流用していた。**今後は選択したグレードと一致する集計のみ数字を表示**する。全グレード混在の数字は「全グレード」を選択したときだけ表示する。
- 個別グレードの集計が足りなければ「集計中／このグレードの掲載例不足」。同じモデル・年式で全グレードの参考値が利用できる場合はその旨だけ短く案内（価格は流用しない）。
- 実際の掲載例から UX250h・2019 F SPORT・一般中古車5台（参考帯340〜360万円、中央値約355万円）、UX250h・2021 F SPORT・一般中古車5台（370〜410万円、中央値約380万円）を追加。UX300h・2024 F SPORT・レクサスCPO7台（参考帯480〜530万円、中央値約512万円）を追加。旧UX200・2019「全グレード6台」は実際にはF SPORT6台だったため、誤解防止で全グレード表記の集計から外した。
- F SPORTの値段を恣意的に上げる、標準仕様の値段を一律引く、などの価格補正は一切行わない。年式・装備・走行距離を合わせた十分なサンプルを今後拡充する。
- 短い結果欄に**価格帯・中央値・集計件数**を残し、必要なときだけ複数年式・走行距離未反映を注記。
- ユーザーからの相談背景：F SPORTと標準仕様が同じ金額に見える条件が多い。値段の差を捏造せず、共通値の誤表示を排除する改善。

## v0.20：ざっくり価格チェッカー（2026-11-11）
- 目的はレクサスUX中古車の購入予算を**気軽に掴む**こと。実際に購入できる車両・在庫の価格保証は行わず、カーセンサー／ガリバーの別ブログパーツ4506へ進む前の目安。
- UIはグレード選択1つ、年式レンジバー1つ、走行距離レンジバー1つ。表示は価格帯1本だけ。一般中古車とCPOの二段比較は廃止。
- **価格は予測モデルや査定額ではない。** 公開承認済みの14区分だけを価格の根拠とし、同グレードの一般中古車例を優先。なければCPO掲載例、同じUXモデルの他グレード例を使用。市場区分を混ぜず、使った根拠・他グレード参照の有無を表示。
- 年式・走行距離の調整はあくまで**編集上の簡易計算**（年式1年差14万円、走行距離1万km差5万円、距離影響±35万円、価格帯は広め、10万円単位の丸め）。これらを実測の減価率と称しない。
- 最新の個別年式／グレード／走行距離を網羅した相場ではない。簡易計算で得た数値がサンプル価格帯の外側へ広がることもあるため、「掲載例から計算したざっくり目安」と明示する。各選択肢で架空の販売車両があるように見せない。
- データの掲載承認・最終確認から60日以内という表示制限は維持。調査例が古くなったら更新表示に切り替え。
- ツール本体にはカーセンサー／ガリバー／CTNなどの広告やボタンを含めず、ブログパーツ4505から同じURLを利用。ブログパーツ4506の購入導線は別管理し、本作業では触れない。
- 旧版のグレード別2段表示の説明は履歴として残す。現在の画面仕様はこのv0.20を優先する。
