# 全国生物図鑑 v1.9 — 底生動物の水系別確認記録を9地方まとめて検索

**2026-10-18作業。GitHub Actions内で生成する研究用データ。つりくえ！本番のWordPress・記事・プラグインには一切反映しない。**

## 新しく実データで追加するもの

国土交通省・河川水辺の国勢調査の [提供データ一覧](https://www.nilim.go.jp/lab/fbg/ksnkankyo/dl_00_index.html) から、河川版の**底生動物の確認種一覧**を9地方で取得する。

- 北海道・東北・関東・北陸・中部・近畿・中国・四国・九州を対象。沖縄の河川版は、公式提供ページで当該カテゴリの一覧が「－」のため**未収録**。
- **9資料とも公開一覧からの直接リンク** `RT81_B02.zip`〜`RT89_B02.zip` を確認済み。
- 個々のソースのSHA-256・ZIP内のExcel名を `benthic_sources_v19.json` に固定。名称「生物項目」「水系」「調査年度」「種名」の公式列配置（C/F/G/J）を9地方すべて検証。
- 最新の独立な種同定・地方自治体の全河川観察・個別河川の生息状況ではなく、**公式河川版データの掲載時点における9地方×水系×調査年度×資料上の生物名**を保持。
- 原表で「底生動物」と明示された行だけ採用。魚類・過去の「魚介類」混合カテゴリなどは**自動で底生動物と見なさず除外**。
- 同名を含む掲載情報を`水系×年度×名前`で重複整理する。この件数は生物の種数ではない。
- 底生動物として掲載されたからといって、種名だけで**エビ・カニ・水生昆虫**へ分類しない。2025年公式分類名との一致は確認・承認前で別の表示。

## プライバシーと地理の粒度

Excelの元資料には観測地点・距離・季節・現場情報等が含まれるが、抽出処理は **C/F/G/Jの4列以外は読まない**。座標、採集地点、自治体、個別支流の情報を生成しない。希少種の観測地点も公開しない。

「地域×生物＝河川」を目指しているが、今回の全国資料で確実に回答できるのは当面「**調査地方×生物名＝調査記録が載った水系**」。地域を特定の都道府県へ狭めたり、水系名を特定の支流へ割り当てたりしない。都道府県の正式な河川・調査記録による別証拠が必要。

## 既存のデータと独立した検索

| 出典の種類 | 検索・保存する情報 | 誤った推論 |
|---|---|---|
| 2025年度「全生物種」名簿37,648行（v1.8） | 和名・学名・門/綱/目/科/属・7分類フラグ | これだけで生息が確認されたとは言わない |
| 9地方の魚類調査18,814行（v1.8以前） | 地方×水系×年度×当時の魚類名 | 支流の魚・釣果ではない |
| **今回の9地方底生動物調査** | 地方×水系×年度×当時の底生動物名 | 川の個別生息・県別分布・同定確定ではない |

集約データは `biota/benthic-staged/<region>/` に保存（GitHub Actions内の一時ファイルとして生成）。ZIP原本・詳細観測はリポジトリに保存しない。

`.github/workflows/river-benthic-v19.yml` が、9地方分のソースを**各ジョブで出典URLとSHA-256照合後に集計**し、公開サイトではなくGitHub ActionsのArtifactsにデータを添付する。

`build_biota_with_benthic_v19.py` は既存の生物分類参考台帳＋魚類調査を再現したSQLiteに、底生動物調査だけ別テーブル `watershed_year_benthic_evidence` として追加。

## 研究用DBの作り方

事前に `benthic-staged` を用意する場合：

```bash
python river-fish/biota/import_national_benthic_v19.py --region chugoku
# 9地域分をそれぞれ同様に実行
python river-fish/biota/build_biota_with_benthic_v19.py --build --db /tmp/biota-v19.sqlite
python river-fish/biota/build_biota_with_benthic_v19.py --db /tmp/biota-v19.sqlite --benthic-name カワゲラ --region chugoku
python river-fish/biota/build_biota_with_benthic_v19.py --db /tmp/biota-v19.sqlite --name モクズガニ --group benthic_animals
```

CIでは原本と学術的参考名簿の違いを検証し、**検索で別々の結果欄に表示**。操作確認用の研究SQLiteをArtifactとしてダウンロード可能にする。成果物の件数は**集計が完了したときの実測数**を使い、事前に推測した全国の種数は表記しない。
