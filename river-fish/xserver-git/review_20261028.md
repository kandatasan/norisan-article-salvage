# 河川魚類接続レビュー（2026-10-28）

対象は main の `atlas.json` にある既存の河川名グループのみ。水系名のみの441件、既存データの外にある資料掲載名16件は分母・新規接続数に含めない。河川IDの新設・統合はしない。

## 着手時の実測

- 魚類調査系の河川名グループ511件のうち、魚名あり352件（`river_fish_label_counts_v25.json`）。
- 川名のみ616件のうち、既存の `fish_source_connections_v01.json` が接続するもの22件。既存25件の対応IDのうち、残る3件は魚類調査系のため重複加算しない。
- 分母1,127件、分子374件、33.19%。50%には564件以上が必要。
- 本番・ci-preview の4代表ファイル（atlas、魚名件数、追加資料v01、index）はそれぞれ同一SHA-256。作業開始時のci-previewは本番と同じ静的データ。

## 今回の審査と追加

- 資料12点を確認。A/Bとして接続候補にした資料9点、10既存グループ、魚名34件（A 18、B 16）。東北・近畿・中国の3地方、4府県にまたがる。
- Aは青森県の図3（旧十川、十川）と大阪府の和田川調査結果表。Bは大阪府の百済川、広島県の岡ノ下川・二河川・堺川・太田川・小瀬川、山口県の佐波川。各行の原資料名、発行者、URL、表・節、資料表記の魚名、年が確認できた場合の年、要約、同一性・保全・公開状態は `source/data/fish_source_connections_v02_additions.json` を参照。
- 基本データの河川名・水系名・県名が完全一致する既存IDにのみ結び、実在する個別河川の地理的な同一性は承認していない。出典にない種への置換、詳細地点、座標は掲載しない。
- 既存273河川詳細ページのIDだけを機械照合してリンク一覧に収録。新しいSEOページは生成しない。

## 検証と反映境界

追加後の分子は384件、384/1,127＝34.07%。50%にはさらに180グループ必要。これは **mainとテスト環境への反映が完了した場合の計算値** であり、PR段階では接続済み・公開済みと称さない。

`validate_atlas.py` は追加行の既存ID完全一致、重複、件数、安全フラグ、詳細ページIDと実ファイルの一致を検証する。GitHub Actionsのステージングのみ利用し、本番用publish/rollback、WordPress、biota APIには触れない。
