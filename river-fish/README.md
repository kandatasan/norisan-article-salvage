# つりくえ！ 川の魚データベース — 公式資料からの初期収録 v0.3

作成日: 2026-10-17。**WordPressや本番DBには未反映**。最初は中国地方5県の公開資料を使う。

## リポジトリに保存したもの

- `curated_fish_records_v03.csv`: **48件**の、資料に魚名が載る水系レベルの記録
- `akaza_local_names_v03.csv`: **12件**のアカザの地方名（広島県内水面漁業協同組合連合会が掲載）
- 県別掲載行数: 広島16／岡山13／島根6／山口6／鳥取7
- 魚名は**30種類の表記**（厳密な30生物種ではない）。例えば「フナ」「フナ類」「コイ類」「スナヤツメ」は種へ勝手に置換しない。

## 大事な区別

1. このCSVは国交省「日本の川」の概説などから抽出した**資料掲載魚名**。正式な「河川水辺の国勢調査」の中国地方確認種CSV原本を取り込んだデータではない。
2. 出典ページに魚名があることと「現地で○年に確認されたこと」は別。調査年が不明の行は空欄とし、公開時に明記する。
3. 天神川の7件は「漁業の対象となっている魚」。放流される魚を含み、独立した野外採集確認の証拠ではない。
4. 地方名の「馬洗川」などは**呼び名の地域**であり、その河川でアカザを採集・確認した地点ではない。魚の地方名検索結果を生息地点に変換しない。
5. 重要種の詳細地点、支流採集地点、座標は公開CSVに保存しない。地域・水系レベルにまとめ、公開可否を別途審査。
6. 魚が登録されていない都道府県・河川は「未収録」。**生息していないとは言わない**。

## CSV の主な列

`prefecture` / `watershed` / `recorded_name` / `evidence_type` / `source_title` / `source_url` / `survey_year`

元の文字表記・出典URL・根拠の種類を優先して残す。検索ページの文言は「○○水系について出典資料に記載」とする。

## 出典と利用条件

国土交通省「日本の川」（各CSV行のURL）と、広島県「レッドデータブックひろしま2021」、広島県内水面漁業協同組合連合会「アカザ」を参照して**つりくえ！側で編集・加工**。

[国交省の利用条件](https://www.nilim.go.jp/lab/fbg/ksnkankyo/Mokj_chui.htm) により、出典・加工の明記が必要。写真や別権利者の著作物は転載していない。行政公開資料であっても、別出典は個別に利用条件を確認すること。
