# 河川名と魚類資料の公開接続・第1便

対象は既存の公開記事 `https://tsurikue.com/japan-river-atlas/`（post 4240）。既存の文章、画像、投稿状態とXserver上の基礎JSONを保ち、記事内の検索プログラムだけに出典別の魚類参照を追加する。

## 今回の資料確認

- 東広島市「令和5年度 主要水域（河川）における水生生物調査の結果」。市の[案内ページ](https://www.city.higashihiroshima.lg.jp/soshiki/seikatsukankyo/5/12/42158.html)から[本編その2](https://www.city.higashihiroshima.lg.jp/material/files/group/19/R5suiseiseibutsu2.pdf)を取得。SHA256 `6033525000deb9812315ad7a5d5e4c6882c51e29cbb7faa84d62a9bee29a8886`。
- PDF p.1–23（紙面p.13–35）の各河川名見出し、流域・本支川の説明、魚類欄を確認。全23ページの魚類欄を原画像でも照合。青字の重要種16セルは除外し、19河川・72河川×魚名×年度の組を収録。同じ川の複数ページは出典位置をまとめ、年・川・魚を二重計上しない。
- これは底生生物調査で併記された魚の記録であり、魚類専用の網羅調査ではない。報告書発行2024年・案内ページ更新2025年を観察年にせず、原資料の2023年を保持。半角カナの原文は `source_literal_label` に保持し、表示名は幅だけNFKCで統一。分類学的な同定・類の分割・別名統合は行わない。
- 資料の調査地点名、橋名、座標、採集日時、個体数、写真を転記しない。川名だけの見出しでも、市内・水系・親支川の説明を併用する。関川は太田川水系三篠川の支川、東川は関川の支川として原資料が説明している。
- 既存のSH22画像照合済み94記載、HINO25画像照合済み57正数セル、および県の河川環境説明を、原資料の記載事実を参照する用途に限定して接続する。HINO25の個体数は今回の出力に含めない。既存ステージング台帳の未承認フラグは変更しない。

## 公開する範囲の判断

保留対象を除外した公開資料の「その河川名について魚名が記載されている」という参照だけを表示する。現在の生息、釣果、川全域での分布、詳細な採集場所、個別河川コード同定の承認は含まない。研究台帳の `not_approved` は個別観測・地理同定等の未承認として維持し、この限定した出典参照の選択を新しい出力層で管理する。

SH22の希少種・要確認36組、HINO25の非公表欄、既存台帳で保全要審査の行は出さない。山口県報告の65河川という調査対象数は、結果表の水系単位と混同せず、今回の追加河川数に使わない。水系だけの記録を支流へ配らない。

## 既存データとの接続

31河川名グループ・261出典記録。15グループはレビューした既存ナビゲーションIDへ接続、16グループは出典由来の名称グループとして追加。

既存国交省群への接続は、斐伊川 `8707040001`、日野川 `8707030001`、法勝寺川 `8707030003` の既存パッケージ内コードと既存の同一性監査を再照合した上で、明示した3つのIDだけを使う。コードを出力しない。県名ディレクトリへの接続は明示ID・県・水系・川名を検査する。水系名だけのIDや複数コード保留群へは接続しない。既存の195所在県未確定群を一括解消しない。

既存の魚類情報と重なる3グループは増加分に数えない。基礎JSONのみの321/1127（28.5%）に対し、記事内追加層を含む見込みは349/1143（30.5%）。分母の追加16群も数える。50%は572群、現在の分母で残り223群。単位は表示名グループであり、実河川の重複解消数ではない。

## 反映と検証

- PR中は認証付きGETのみ。現行の公開記事、スラッグ、アイキャッチ、タイトル、既存スクリプトSHA256を確認。
- mainへ監査後マージした時だけ、公開記事内の一致する実行スクリプトを置換。直前の再GETが一致しない場合は停止。
- 保存後に全保護メタデータ・本文の他部分・レンダリング済み実行スクリプトを確認。
- 公開URLを新規GETして埋め込み層とリポジトリの完全一致を確認し、基礎JSON＋記事内追加層の合算率を監査。Actions artifactに報告を保存。
- 既存の `audit_live_atlas_fish_coverage_v01.py` は基礎JSON専用の指標のまま。最新の画面上の率は `audit_connections.py` を使い、二つの層の率を取り違えない。

## 第2便：既存の東京都空欄10グループに区の魚類調査を接続（2026-10-25）

世田谷区の[令和7年度魚類調査表](https://www.city.setagaya.lg.jp/documents/4835/r7gyorui.pdf)（SHA256 `1bc435cb869134b3deb1b0f9db344fbd16b7a7add17e0c910056dcb42ec8b566`）、足立区の[令和5年度報告概要](https://www.city.adachi.tokyo.jp/documents/51477/r5gaiyou.pdf)（`e3819175c15183ca567b08936a6183cbdbdf8f58afceab8a4994e3949c43ebfd`）、中央区の[令和5年度魚類調査表](https://www.city.chuo.lg.jp/documents/15719/gyorui.pdf)（`547292cc7f806f2c90c0123c2e2d49fd1cf55e64ff15994021abf6d9bb7cdf95`）を各PDF p.1の原画像で確認した。調査表の河川列・見出しと魚名の陽性記録が一致するものだけを採る。3区の案内ページにある年度と原表の調査年を確認し、ページ更新日を調査年として使わない。

世田谷区の野川・仙川・丸子川、足立区の綾瀬川・垳川・毛長川、中央区の神田川・日本橋川・亀島川・築地川の計10グループに、各1件の出典別魚名参照を追加する。現行アトラスの東京都ナビゲーションには各名が一意の既存IDで存在し、基礎魚名索引に陽性行はない。水系欄は「水系未確認（公式資料の川名）」のままとし、区の調査から流域・支川・全国河川コードを推定しない。荒川・隅田川など対象外の河川へ転記しない。

東京都レッドリスト2020年見直し版も照会し、掲載種や足立区資料の重要種表示をこの追加層に採らない。谷沢川は表に陽性記録があるが今回の選定では保全確認を終えられないため保留。各河川1件という出典参照は魚類相の網羅数ではなく、採集地点・個体数・写真・座標・河川コードを出さない。既存の検索では魚名と川名の両方向で参照できるが、現在の生息や釣果は保証しない。

追加層は計41グループ・271出典記録となり、16の資料由来新規グループと基礎JSONは増やさない。公開前の計算は **359 / 1,143（31.4%）**、50%まで **213グループ**。実績への加算はmain反映後の公開記事監査で確認する。WordPressでは記事4240の既存実行スクリプトのハッシュを照合してその部分だけを置換し、本文・メタデータとXserverの基礎JSONを保つ。
