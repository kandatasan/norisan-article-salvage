== Description ==

管理者が手動で読み込んだ公式資料の「河川コード名」「都道府県の資料に載る名称」
「水系・調査年度別の魚類記録」を出典・範囲別に検索します。

* 全国河川コード名 35,449 件。コードは所在地県の確認資料ではありません。
* 都道府県資料 1,449 掲載行。各県の全河川網羅ではありません。
* 国交省魚類記録 18,814 件。水系×年度×魚名の記録で、特定支流の生息魚ではありません。

データの同一性照合や希少種の位置推測はしません。

== Installation ==

1. この ZIP をプラグイン → 新規追加 → アップロードで設置します。
2. 有効化時は専用テーブル作成のみ。データ読み込みも投稿公開も行いません。
3. 管理画面の「ツール → 全国河川DB」で「取込を開始」を押します。
4. 55,712 行の取込が完了するまで管理画面を開いておきます。途中で止まった場合は「中断した取込を再開」を押します。
5. 取込完了後、非公開の下書きページに [tsurikue_river_search] を入力してプレビュー確認します。

前の世代のデータがある場合、新しいデータを未使用の世代に取込み、検証が全て通った時点で切り替えます。
解除・無効化してもデータは自動削除しません。

== Safety ==

公開検索は読み取り専用REST GET。インポートは管理者権限とnonceを要求。
専用の3テーブル以外の投稿・カテゴリー・既存WPテーブルは変更しません。
サーバーがデータを書き込めるか、容量・MySQL権限の確認が必要です。
WordPressの既存バックアップを確保してから手動取込を行ってください。

== Source ==

日本の都道府県・自治体公式河川関連ページ。加工済の研究用データ。
コード・現地魚類・県内河川の網羅確認ができたことを意味しません。
商用サイトでの公開には、各原典の利用条件と一次資料の名称の追加監査が必要です。
