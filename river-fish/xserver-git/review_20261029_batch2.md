# 河川魚類接続レビュー 第2便（2026-10-29）

対象は既存の未接続河川名グループのみ。河川名グループの追加・削除・統合は行わない。

## 採録

- 公的資料3点を再確認し、5既存グループ、魚名6件を接続候補化した（A 1件、B 5件）。
- 岐阜県の大江川は、河川整備計画の河川別説明に明記されたフナ類、モツゴをB「資料に掲載された生息魚」とした。
- 埼玉県の綾瀬川は、2021年に網等による捕獲と直接観察を行った現地調査から、保全対象ではないタイリクバラタナゴ1件をA「魚類調査記録」とした。
- 埼玉県の大落古利根川、神流川、赤平川は、県環境科学国際センターの魚類研究成果から作成された県資料の河川別掲載をBとした。個別記録の調査年度を資料から分離できないため年は補完していない。
- 詳細地点は収録していない。原資料の魚名を確定種へ置換していない。
- 大江川は既存データの水系表示が「水系未確認」のため変更せず、原資料の木曽川水系を `documented_watershed` に分けて保持した。

## 保全・同一性審査

- 横瀬川のヤマメは河川名との対応が明確だが、埼玉県レッドデータブック2018でVUのため公開接続を保留した。
- 神流川のカジカは同レッドデータブックで、生息状況が安定し容易に採集されるとしてリスト外とされたことを確認した。公開データには資料掲載の市町名を移さない。
- 綾瀬川のドジョウ、ミナミメダカは同じ現地調査で確認できるが、資料自身が保全対象としているため公開接続を保留した。
- 千旦林川は3河川を合算した調査結果しか確認できず、河川固有の魚名を分離できないためC相当として保留した。
