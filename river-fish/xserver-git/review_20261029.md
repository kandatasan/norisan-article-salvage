# 河川魚類接続レビュー（2026-10-29）

対象は既存の未接続河川名グループのみ。河川名グループの追加・削除・統合は行わない。

## 採録

- 公的資料3点を再確認し、8既存グループ、魚名30件を接続候補化した（A 6件、B 24件）。
- 岐阜県の可児川、坂本川、飛騨川、矢戸川、久々利川、唐沢川、加茂川は、各河川の節に明記された一般的な魚名をB「資料に掲載された生息魚」とした。
- 埼玉県の元荒川は、2021年に網等による捕獲と直接観察を行った現地調査の河川別結果から、一般魚6件をA「魚類調査記録」とした。
- 希少性に懸念がある魚名、保全対象魚、調査地点、細かな区間は公開データに移していない。属・類の表記は確定種へ置換していない。
- 岐阜県7河川は既存データの水系表示が「水系未確認」のため変更せず、原資料の木曽川水系を `documented_watershed` に分けて保持した。

## 保留

- 千葉県の根木名川は、検索索引では魚名を確認できるが、原PDFの文字抽出で水域と魚名の対応を再確認できず保留。
- 新潟県の三面川は、水系全体と本川の記述範囲の再確認が必要なため保留。
- 岐阜県の津屋川は魚類17種との記述のみで魚名がなく、接続対象外。
